# 05 · 拍板纪要 —— 模板

> **使用方法**：复制本文件 → 改名为 `05-拍板纪要-YYYY-MM-DD.md` → 当场填完 → 提交。
> **填完后必须做两件事**：① 把 `docs/00-INDEX.md` 第 2 节的「四层真相」表里本文件的状态从 ⏳ 改为 ✅；② 若本次拍板推翻了 `docs/03` / `docs/04` 的内容，在它们文件头加一行 `⚠️ 本文件已被 05-拍板纪要-YYYY-MM-DD 部分取代`。
>
> **为什么需要这份模板**：仓库目前有四层互相不完全一致的结论，且没有任何一份文件记录"真人到底拍了什么"。没有纪要，两周后所有人（包括 AI）都会从不同文件里读出不同的"当前真相"。
