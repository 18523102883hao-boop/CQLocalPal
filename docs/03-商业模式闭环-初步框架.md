# 03 · 商业模式闭环 —— 初步框架（v0.1 草案）

> 状态：**初稿**。基于 2026-11-02 首次会议纪要整理。待后续输入（会议录音、线下团队讨论、商业模式概念视频）后迭代为 v1.0 执行方案。
> 迭代方式：每次重要讨论后更新本文件版本号，并在文末「变更记录」留痕。

## 一、闭环总览

```
获客（外网内容+投流） → 首次免费/低价体验 → 服务群承接 → 服务交付（真人助理）
     ↑                                                      |
     └────────── 口碑传播 / 复购与转介绍 ← 折扣与好体验 ←─────┘
                        小程序为后端承接与变现放大器
```

## 二、获客（Acquisition）

| 渠道 | 形态 | 要点 |
| --- | --- | --- |
| TikTok / Facebook / Instagram | 个人账号 + 轻投流 | 真实服务案例内容（老外第一视角）；不做大而全官方号 |
| YouTube / 游记博客 | 长内容沉淀 | 重庆赛博朋克/8D 城市内容承接海外既有热度 |
| 口碑与转介绍 | 游客小群裂变 | 服务好 → 同团/同 hostel 游客互相推荐 |
| 线下触点（中期） | 机场/高铁展示位、文旅委背书站台 | 增强信任背书；属于第二阶段，非启动依赖 |
| 并行线（杰文） | 重庆景区上架海外 OTA 平台 | 已申请 2–3 家，流程繁琐推进慢；作为支线继续跑 |

**关键判断**：启动不依赖任何机构审批；外网个人账号 + 投流即可开始接私人小团。

## 三、服务（Service）

**产品形态**：按游客（或小团）建立专属服务群，真人助理实时在线。

| 服务层 | 内容 | 定价思路 |
| --- | --- | --- |
| 基础助理（引流款） | 问答/攻略咨询、路线规划、餐厅与点位精准匹配（知识库驱动） | 低价或按次，制造「离不开」的体验 |
| 事务代办（利润款） | 订酒店、订车、门票——凭资源拿折扣，赚价差 + 服务费 | 游客网上可查到原价，找我们反而更便宜 |
| 深度定制（溢价款） | 私人小团、特色体验定制（户外徒步、亲子、本土烟火气路线） | 按人头/按天收费 |
| 应急协助（信任款） | 夜间协助、纠纷调解、证件/支付障碍处理 | 含在套餐或按次收费，核心是信任资产 |

**核心竞争力**：
1. 重庆本地吃喝玩乐知识库（持续调研：风景好、味道好、环境特别的点位）；
2. 资源折扣能力（酒店/车队/商户合作返佣 + 给游客的让利）；
3. 「反 AI」真人实时响应的确定性。

**测算锚点**（团队共识）：一年服务 1000–5000 人、月均约 500 人、日均几十人，生意即非常 OK；做得好招两人，做不好自己慢慢做，起码不亏。

## 四、交付（Delivery）

1. **触点建立**：外网内容/私信 → WhatsApp / WeChat / 邮件 → 建专属服务群；
2. **履约**：助理 + 知识库响应；酒店/车辆/门票代订走合作资源；
3. **承接放大**：小程序作为后端承接与变现工具——护照+邮箱注册（免国内手机号）、国际信用卡支付、精选商户与路线产品化；
4. **沉淀**：服务评价与案例回流为外网内容素材，反哺获客；
5. **合规交付（中期）**：海外公司（东南亚/美加）负责外网投流、收款与结算。
