你问的是"哪种模式对"。真问题是：**四个 AI（包括我）在纸面上辩论了一个竞品已经存在、而你们没有买过任何一件竞品、没有和任何一个真实游客说过话的市场。** 当下最高价值动作不是第五份方案，而是花 ¥200 买 Jay Chongqing Tour 的 concierge、花 ¥400 报一个 GYG 拼团，拿到一手竞品事实；再用 10 天做"能否触达 20 个陌生人"的流量微实验。模式辩论应在这两组数据回来后收敛，而不是在 Round 3 之后。

### 4. 预测我最容易给出的标准答案、它的三个缺陷、更好的版本

**标准答案**（我若不克制就会写的）："做首晚/落地确定性产品，持牌社合作，真人品牌 + AI 后台，内容 + 社区 + OTA 获客，小规模付费验证，设硬停止线。"
**三个缺陷**：
1. 与 Codex Round1 模式 A、Kimi 三层 SKU 高度重合——四方趋同不增加任何证据（Codex Round1 §2 自己说"模型赞同不是新增事实"）；
2. 默认"验证=有人会买"，回避了淡季样本偏差和幸存者偏差（看得见的 Jay/Anjia 可能是死掉十家后的幸存者）；
3. 回避了创始人外籍身份这个硬约束，给的是"团队方案"，实际是"一人公司"。

**更好的版本**＝本报告主体：把"买竞品→流量微实验→身份合规摸底"排在一切产品验证之前；把产品形态从"私人陪同"改为"固定班次拼团"（唯一能让早期单位经济转正的结构）；把 6 个月计划建立在"创始人不能亲自带团"的悲观假设上；并诚实给出天花板测算。

## 六、法规红队（只列新增发现，不重复 09 §10.3 / 审查 M9）

### 6.1 一号风险：创始人外籍身份（全仓库无人处理）

会议纪要（R10）：创始人持外国护照、今年 3 月以 240h 免签身份入境中国、计划未来在东南亚/美加注册公司。若其已加入外籍（自动丧失中国户籍/身份证 [事实-《国籍法》第 9 条框架]），则：

1. **他本人不能合法"亲自带团收钱"**。外国人在华工作须持《外国人工作许可证》与工作类居留证件 [事实-框架，《出境入境管理法》第 41 条、《外国人在中国就业管理规定》]；持旅游/免签入境身份从事经营性陪同服务＝非法就业风险。
2. **导游证大概率拿不了**：全国导游资格考试历版报考公告通常要求中华人民共和国公民 [事实-需以最新考试公告与律师核实，标注**待验证-高优先级**]。即"创始人自己成为持证英语导游"这条路可能根本不存在。
3. **公司结构连锁问题**：他持股的境内公司属外商投资企业（备案/准入）；用亲友代持＝代持纠纷与合规双重风险；他计划的"海外公司收款+境内交付"涉及跨境服务贸易、代扣代缴、外汇真实性审核 [事实-框架]——09 §9.7 提过支付实测，但没人把"创始人身份"作为支付/主体问题的根因。
4. **对 Kimi B3 的直接反驳**：Kimi 把"创始人的外国护照"称为核心品牌资产。**方向反了**——它首先是合规负债（不能履约、不能持证、就业身份存疑），其次才是内容资产（"外籍人士做重庆本地通"是好选题、好故事，但兑现方式是**出镜做内容和品控，而不是亲自接单**）。

**行动**：律师首询三件事——(a) 创始人当前签证/居留身份下可合法从事的活动边界；(b) 境内主体注册路径（外资 vs 代持 vs 合伙）；(c) "拼团步行体验 + 摄影交付"结构下 host 的导游证必要性。此项未完成前，**任何收费交付都只应由持牌社委派的中方人员执行**。

## 十二、KPI Dashboard / Go-Pivot-Stop

**月度加看**：渠道 ROI 排名（每渠道：对话→报价→成交→CM2 回收）、OTA vs 自渠道占比、复购/转介绍率、host 利用率、B2G/邮轮管道金额。

| 判定 | 条件（M3 末初评，M6 末终评） |
