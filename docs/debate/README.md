## 命名规范

- 独立方案：`YYYY-MM-DD-Round0-<Model>-独立方案.md`
- 交叉质询：`YYYY-MM-DD-Round1-<Model>-对其他方案的质询.md`
- 回应与修正：`YYYY-MM-DD-Round2-<Model>-回应与修正.md`
- 最终收敛结论：`YYYY-MM-DD-Decision-Memo-最终融合推进方案-vX.X.md`

## 辩论规则

1. 不得把未核验信息写成事实；必须严格标注 `[事实]`、`[公开观察]`、`[假设]`、`[判断]`。
2. 必须同时回答：支持本方案的证据、最可能失败的原因、最小验证动作、放弃条件。
3. 最終结论已同步回写至 `docs/03-商业模式闭环-初步框架.md`（v1.0）与 `docs/04-任务清单与路线图.md`（v1.0）。
