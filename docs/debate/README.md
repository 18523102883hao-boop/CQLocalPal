## 辩论规则

1. 不得把未核验信息写成事实；必须严格标注 `[事实]`、`[公开观察]`、`[假设]`、`[判断]`。
2. 必须同时回答：支持本方案的证据、最可能失败的原因、最小验证动作、放弃条件。
3. 最終结论已同步回写至 `docs/03-商业模式闭环-初步框架.md`（v1.0）与 `docs/04-任务清单与路线图.md`（v1.0）。
