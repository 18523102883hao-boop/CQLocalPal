# docs/debate · 多 AI 辩论工作区

**机制**：Codex、ChatGPT、Kimi（本助手）、Claude 四方各自独立提交方案 → 相互辩驳 → 项目发起人（人类）做最终裁决并整合。

**流程**：
1. **Round 0**：各方提交独立方案，文件命名 `YYYY-MM-DD-RoundN-提交方-主题.md`。
2. **Round 1**：各方阅读他人 Round 0 后提交辩驳，固定结构：Agreement / Disagreement / Evidence / Counterargument（自辩最强反对）/ What would change my mind / Decision implication。
3. **Round 2+**：围绕最大分歧聚焦反驳。
4. **Decision Memo**：由发起人（可委托任一 AI 起草）整合共识与保留分歧，写入 `docs/debate/`，并回改 `docs/03-商业模式闭环-初步框架.md`。
