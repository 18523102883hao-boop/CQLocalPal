# A. 一页纸执行简报（5 分钟版）

**一句话定位**：CQLocalPal 先做“有具名真人、可确认、可退款、有人负责”的重庆入境游客执行服务；AI 藏在幕后降本，不卖 AI 攻略。

**市场 3 个硬数字**

- `[事实]` 2025 年重庆入境游客 214.78 万人次、花费 23.98 亿美元（`docs/research/09-重庆本地通-入境游综合调研报告.md`，官方统计口径）。
- `[事实]` 2026H1 江北机场口岸外籍 61 万余、同比约 +86%；免签/240h 入境 21 万余、同比约 +83.6%；前五为泰、马、新、越、印尼（`docs/debate/2026-11-02-Round0-Claude-独立方案.md`，援引市政府发布）。
- `[公开观察]` Jay Chongqing Tour 仍在售 ¥200/trip concierge；Anjia 展示持证/评价/SEO 页面；说明需求存在，但“执行层空位”已不存在（`docs/research/12-外国用户视角与海外同类服务调研-2026-11-02.md`、`Round0-Claude`）。

**今天新增的 3 个最重要事实**

1. `[事实]` 竞争者已覆盖远程支持、首晚/步行、layover、武隆/大足等组合；我们是第 N 名进入者。
2. `[事实]` `渝府办发〔2026〕27 号`在 2026 年底前推进双语标识、涉外志愿队、多语手册，同时形成 B2G 服务采购口子（`Round0-Claude`）。
3. `[事实/待核验]` 创始人外籍身份可能影响带团、讲解、收费、劳动/导游/税务责任；全仓库此前没有完成法律核验。

**四方共识（明天不再争）**

1. 不做大平台、原生 APP、AI 攻略 App；先网页/问卷+人工交付（`00-AI-CONTEXT`、Codex/Claude/Kimi/ChatGPT）。
2. 合规主体、收款、保险、退款和责任先于销售（`00-AI-CONTEXT`、两份审查）。
3. AI 做信息整理和后台提效，价值在本地确认、现场执行、异常处理、责任承担（`00-AI-CONTEXT`、`12`）。
4. 早期必须用真实付费和逐单 CM1/CM2/CM3 验证，不能用点赞、口头喜欢或免费换帖代替（Codex 14 天草案）。
5. 0–3 个月先高意图自然获客，广告后置；禁止买评、买粉、激励评价（`12`、`00-AI-CONTEXT`）。

**明天必须拍板的 5 件事**

1. 现金上限与第 6 个月目标：A ¥1.5 万/月小而美；B ¥5 万/月；C ¥15 万/月则换 B2B/B2G/赛道。
2. 首发 SKU：我建议“固定班次 First Night 拼团”为主；私陪只做高价补充。
3. 远程支持：先做加购（+¥99/组），独立 ¥199 仅作对照实验。
4. 合规路径：持牌社作为收款/合同/保险/委派主体；外籍创始人先不承诺带团。
5. 渠道排序：直客高意图内容/社群 → 到达场景轻触点 → OTA 借壳 → 酒店 B2B；机场/文旅委先谈不依赖。

# B. 完整综合方案 v2.0（30 分钟版）

## 1. 客群与产品

P1：首次来渝、2–4 人、3–4 晚、英语或目标语言可上网、对落地执行失败敏感；P2：在华外籍/商务延住，作为现金流；P3 家庭/多代后置。东南亚首发顺序：泰国、马来西亚、新加坡、越南、印尼各做小样本；英语是基线，不把国籍等同语言。[事实/判断，`00`、`12`]

**英雄 SKU（我的裁决）**：`First Night Chongqing` 固定班次 3 小时英文小团，2–6 人成行，¥399/人；1–4 人私享 ¥899/组仅在拼团未成行时作为升级。含集合、山城街区、点餐协助、定位卡、10 张照片、24h 群答疑；不含餐/门票/车。理由：拼团可摊薄 host 固定成本；照片和首晚结果易理解、易传播。[判断，源自 Claude Round0、Codex Round1、Kimi B5；与 Codex 私陪优先不同]

A2 山城轻徒步 ¥459/人，作为第二场景；B 72h 远程支持 ¥199/组、A 加购 +¥99，严格 3 次/60 分钟/09:00–21:00；C 武隆/大足持牌包车 ¥2,600–5,800/团，后端利润。[假设，`Round0-Claude`、Kimi、Codex 双产品草案]

## 2. 获客双闭环与渠道裁决

闭环一（行前）：英文首晚/支付/机场 SEO 页面+Reddit/Facebook/YouTube Shorts → 落地页 → WhatsApp 真人 → 持牌社付款。

闭环二（行中）：青旅/民宿台卡、行李寄存点、外籍社群、在华商务/亲友 → 首晚或远程 → 转介绍/近郊升级。

渠道排序：1 直客高意图内容；2 到达轻触点；3 OTA 借壳；4 酒店 B2B（30 单后）；5 机场/文旅委（拿案例后谈）。我不同意 Claude 将机场点位列 M2 但几乎后置的处理：它不是启动依赖，却应在 W8–12 带数据试谈。酒店不是冷启动引擎，因 BD 周期和青旅低 WTP。[判断，Kimi B4、`12`、Round0-Claude]

## 3. 合规结构

持牌旅行社/合规商户做合同、收款、发票、保险、退款和供应商委派；CQLocalPal 做品牌、需求采集、内容、客服和质量监督。外籍创始人未完成法律意见前不带团、不以导游身份收费、不签“个人免责”。必须核验工作许可、导游证/国籍限制、旅行社责任险、外卡收款与 chargeback。[事实/假设，`00`、审查-来源与事实、Round0-Claude]

## 结论与自我反驳

我不同意 Decision Memo v1.0 至少三点：①它把拼团裁决写得过满，拼团仍需用 P1 付费偏好验证；②它把机场/文旅委过度后置，正确做法是服务跑通后 W8–12 带数据试谈；③它把外籍身份列为最大盲区虽有根据，但获客可达性和单位经济同样可能先杀死项目；④其月10–40团天花板是链式假设，不能当预测。[判断，依据 `Decision-Memo`、Round0-Claude、Kimi B4/B5、Codex 14天草案]

# 附录四：被浪费劳动、假设冒充事实与数字冲突

1. **四方同源幻觉**：多份报告引用同一官方统计、同一公开竞品页面、同一 Reddit/论坛样本，却把四次表述当四份证据。统一口径：同源只计一次，报告作者只增加解释不增加事实等级。
2. **“东盟72%”误用**：分母是口岸外籍旅客，不是重庆游客、英语游客或付费用户。统一写法：`[事实] 口岸外籍来源结构；[假设] 目标客源；[待验证] 语言/WTP`。
3. **214.78万与76万不能相加**：前者为入境游客统计口径，后者为口岸外籍出入境人次；不能当同一市场规模。
4. **退款率口径不一**：有的文件用“退款/订单”，有的用“退款金额/GMV”，有的把改期算退款。统一：退款订单率、退款金额率、chargeback率分列。
5. **毛利差异**：¥899私享、¥2,600–3,600城市包、¥399拼团使用不同成本边界。统一CM1/CM2/CM3三层，所有创始人免费工时按影子时薪计入CM3。
6. **“月10–40团”是假设区间**：不是已观测天花板；必须写出每一步分母、转化率、可服务天数和渠道容量。
7. **“折扣/优惠”被当作已存在供给**：没有RFQ、采购量和有效期，不可写入产品毛利。
8. **“外卡可收款”被当成能力**：Stripe/PayPal/微信/支付宝只是候选，必须实测成功、退款和拒付。
9. **“竞品存在=我们能卖”逻辑跳跃**：竞品证明需求存在，不证明新品牌可获客、可盈利。
10. **“免费换帖”被混用**：客户证言、平台评价、创作者内容是三种不同机制；不得以免费/折扣换好评。

# 附录六：任务二批判性审计

## 1. Decision Memo v1.0

**五大共识遗漏**：把“可问责执行”写成共识，但真正分歧在“谁来承担责任、以什么产品收费”；把“酒店不是主线”写成接近裁决，实际只是渠道假设；没有把东南亚语言/WTP、杰文OTA线、户外资源列为同等级未决问题。

**月10–40团压测**：

- 外籍入境人数：来源口径不同，不能直接作为可服务游客数；
- 英语FIT占比：未观测；
- 愿意购买本地服务比例：未观测；
- 新品牌可捕获比例：未观测；

## 2. Codex双产品14天草案

14天在11月淡季的结论效力低：它能判断“在当前窗口、当前渠道、当前报价下是否出现早期付费”，不能估计全年需求。必须增加：

- 同一游客组A/B展示顺序交替；
- 熟人、在华外籍、真实入境游客分层；
- 把“未触达”与“看过报价未买”分开；
- 记录季节、提前预订天数、语言、人数、来源；
- 至少两批样本、延长至30天或覆盖1个旺季窗口；
- 6–10单只作交付学习，不能宣称市场成立；
- 失败时先判断“入口失败/价格失败/产品失败/合规无法售卖”，再停。

# 附录八：为什么我不同意 Decision Memo 的三点及自我可能错误

1. 不同意“拼团几乎唯一解”：它是当前成本假设下的优选，不是已验证事实；私陪仍需保留为高价对照。
