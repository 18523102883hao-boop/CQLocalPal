## 一、国际顶级网站设计亮点拆解（信任感从哪来）

### 1. Airbnb —— 信任 = 真人 + 真实照片
- 全站无 stock 感：房东/体验达人的真实人像、真实房源照片，脏一点的生活气反而加分；
- 社交证明前置：评分、评价数、"Superhost"徽章出现在列表第一屏，而非 bury 在详情页；
- 设计手法：大面积留白 + 圆角卡片 + 柔和阴影，CTA 用品牌玫红高对比，全站只有一个主按钮色。
- **我们拿走**：团队真人照（含外国护照创始人的"老外视角"叙事）放首屏；评价数与徽章前置；单主色纪律。

### 2. GetYourGuide / Viator —— 信任 = 低决策成本
- 价格、时长、取消政策、即时确认状态在同一卡片内闭环，用户不用点开就知道全部关键信息；
- "Reserve now & pay later" 把支付压力后置；
- 设计手法：信息密集型但网格严格对齐，徽章体系（Likely to sell out / Free cancellation）制造确定性。
- **我们拿走**：产品卡片必须"价格+时长+含什么+取消政策"四要素闭环；"Free cancellation" 类确定性徽章直接抄作业。

### 3. Stripe / Linear / Vercel —— 开发者级审美 = 高品质的潜意识信号
- 排版即设计：超大号衬线或几何无衬线标题 + 充足字距，一屏只说一件事；
- 动效克制：滚动淡入、微位移，绝不闪烁弹窗；
- 深色 hero + 浅色内容区的节奏对比；网格系统严格（8pt 基数）。
- **我们拿走**：这类审美是"AI 模板站"最难伪造的质感——我们的官网要在视觉密度和克制感上像一家 SaaS 公司，而不是一家旅行社。

### 4. Black Tomato / Indagare（高端定制游）—— 信任 = 编辑级内容
- 杂志式排版：衬线大标题、沉浸式全幅摄影、留白奢侈；
- 先卖"想象"再卖"产品"——首页讲故事，行程页才谈规格。
- **我们拿走**：内容页的杂志式排版；但避免其"太重"的毛病（加载慢、转化路径长），我们是轻量版。

### 5. 反面教材（我们自己竞品实测）
- Jay（Airo 模板）：布局雷同、无品牌字体、评价弹窗打断浏览——"模板感=小作坊感"；
- 240：功能强但平台感重、人格缺失；
- Anjia：内容好但视觉中庸，设计感配不上内容质量。
- **结论：设计感是三家共同的短板，是我们可以"不战而胜"的维度。**

## 二、CQLocalPal 设计语言系统（v0.1 草案）

| 层 | 决策 | 理由 |
|---|---|---|
| 气质关键词 | **"Local friend, professional backbone"**——朋友的温度 + 专业机构的骨架 | 与 Jay 的"个人导游"、Anjia 的"传统旅行社"都区隔开 |
| 主色 | 深墨绿/午夜蓝为底 + 一个高饱和点缀色（辣椒红或霓虹紫，呼应重庆夜景） | 深色 hero 出品质感，点缀色呼应赛博朋克城市心智 |
| 字体 | 标题：现代几何衬线（Fraunces / Instrument Serif）；正文：Inter / General Sans；中文：系统栈 | 衬线标题=编辑信任感；Inter=国际互联网母语 |
| 摄影 | 真人实拍 > 一切：团队成员、服务实拍、客人（授权）瞬间；禁止 stock 图 | Airbnb 经验：真实>精美 |
| 动效 | 仅滚动淡入 + 图片视差；单页动效预算 <100KB JS；无弹窗无轮播 autoplay | 克制=品质；性能=信任 |
| 排版 | 一屏一事；正文行宽 60–75 字符；8pt 网格 | Stripe 式纪律 |
| 组件纪律 | 全站唯一主 CTA（WhatsApp 咨询）；次级动作用 ghost 按钮 | 转化聚焦 |

**首页叙事顺序**（认知→认同→认购）：① 一句话定位 + 真人画面（认知）→ ② 客人真实评价与第三方徽章（认同）→ ③ 产品卡三要素 + 透明价格（认购）→ ④ WhatsApp 即时响应承诺收尾。

## 三、信任清单（Trust Checklist，上线前逐项打勾）

- [ ] 团队真人照 + 具名 + 创始人外国护照视角叙事（独家，无人可复制）
- [ ] 执照挂靠信息公示（许可证号、主体公司，学 Anjia 但更透明）
- [ ] Trustpilot / Google 评价组件（第三方托管，非自站审核——攻击 Jay 的全 5 星精修橱窗）
- [ ] 评价不筛选承诺（"We publish every review" 作为品牌承诺写进价值观）
- [ ] 透明价格页（学 Anjia 的锚点定价，但做到 Jay 级的全公开）
- [ ] 响应时效承诺（"Reply within 30 minutes, 08:00–24:00 CST"——赢过 Anjia 的 2h/限时）
- [ ] 取消政策前置（Free cancellation 徽章进产品卡）
- [ ] 真实地址 + 地图 + 电话/WhatsApp/微信三通道
- [ ] 性能：LCP < 2.5s（4G），CLS ≈ 0（性能本身是品质信号）
- [ ] schema.org：LocalBusiness + Product + Review 结构化数据（SEO 与信任双赢）

## 四、技术路线（决策已做，附理由）

| 项 | 选型 | 理由 |
|---|---|---|
| 框架 | **Astro 5.x（静态优先 + Islands）** | 几乎零 JS 默认输出 → Core Web Vitals 满分级；内容站最优解；对手是 React SPA（重），我们在速度上碾压 |
| 语言 | TypeScript | 稳定性与可维护性 |
| 样式 | Tailwind CSS 4 | 设计系统可约束在 token 层，防止"AI 生成式混乱"；与 Figma 变量一一对应 |
| 内容 | MDX + Content Collections | 博客/攻略即代码，i18n 友好（对手 240 的 231 篇内容集群我们用同样架构复制） |
| 多语言 | Astro i18n 路由，先 en 后 th/vi/id | 对应客源国；Jay 只有英文 |
| 托管 | Cloudflare Pages（或 Vercel） | 免费 + 全球 CDN + 中国大陆访问相对友好 |
| 表单 | 静态 + Formspree/自研 Worker（先不接支付） | 订金走收款码人工核销（Jay 已验证模式），零支付合规负担 |
| 分析 | Plausible（自重）+ FB Pixel（投放期） | 合规 + 投流两用 |
| 图片 | AVIF/WebP + `astro:assets`，摄影图进 Git LFS/对象存储 | LCP 关键 |
| 域名建议 | 品牌名 .com + .cn 双注 | — |

**为什么不用 AI 建站工具（Airo/Wix/Framer）**：模板同质化（等于告诉客人"我是小作坊"）、设计无法落到 token 级控制、SEO 天花板低、数据与样式 lock-in。我们的优势恰恰是"有技术品味"——把网站当成产品做。

## 五、执行顺序（设计先于开发）

1. **产品拍板**（今天下午）→ 品牌名/Slogan 定稿（过《人心红利》三点合一检验）；
2. **设计稿**：Figma 出首页 + 产品页 + 价格页三屏高保真（1–2 天）——这一步决定 80% 的品质感；
3. **Demo 开发**：Astro 静态站，3–5 个页面（首页/产品/价格/评价/关于），英文内容，先接 WhatsApp 转化（2–3 天）；
4. **内容启动**：首批 5 篇攻略（chongqing first night / is chongqing safe / alipay setup for foreigners / 3 days in chongqing / non-spicy food guide）——对标 Anjia 集群 but with our angle；
5. 投放验证期看数据迭代；泰/越/印尼语版本排期到验证后。

**性能预算（写死，超了就不上线）**：首屏 JS gzip < 90KB；CSS < 30KB；LCP < 2.5s；Lighthouse 移动版 ≥ 95。
