### 技术洞察（直接喂给官网技术路线赛马）

1. **赛道分两派**：现代 React/Next 派（TBL、Withlocals、240——HTML 体积 540–880KB）vs 轻量传统派（China Highlights 193KB、Civitatis 283KB、Anjia 30KB）。**做得大的未必技术新，Civitatis 用 PHP 做成了西语市场第一、CH 用 Bootstrap 做了 20 年**——验证了 Lawson 文章论点：内容与服务才是壁垒，框架不是。
2. **240 的 11 语种是 Next.js 实现的**——说明多语言与 React 栈可以共存，但它 878KB 的 HTML 体积也付出了性能代价（我们的四语种架构无论选什么栈都要控制单页体积）。
3. **Context 坚持用 Rails** 且客单价全场最高（US$1,000+ 多日产品）——再次印证：高端品牌拼内容深度与信任，不拼前端框架新旧。
4. **对本项目的意义**：Astro 方案（静态优先、小 HTML）在数据上同时占优——比 Next 派快一个量级，比传统 PHP/Bootstrap 派又更具 AI 开发效率与现代 SEO 特性（结构化数据、图像优化）。**这是把赛马各方方案放进来对比时的基准线数据。**
