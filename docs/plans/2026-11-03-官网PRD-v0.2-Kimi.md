## 一、产品定位与目标

**一句话**：官网是外国游客从"认知→认同→认购"的完整转化机器，也是"外国人自己做的本地服务商"这一信任定位的第一证据。

**北极星指标**：询单转化率（访问→WhatsApp/预订发起）≥ 3%；次指标：评价阅读率、攻略页停留时长。

**设计哲学**：
1. **审美即战略**——竞品（Jay/Anjia）网站多为平庸外包/AI 产物，我们用技术品味形成第一眼信任差。宁可晚上线一周，不可丑着上线。
2. **先参考顶级，再动手**——设计标杆清单见 17 号文档；视觉对标欧美高端旅行品牌的克制感。
3. **技术路线：证据驱动， Lightweight wins**——见第六章（本轮重写）。

## 二、信息架构（IA）

URL 统一带语种前缀：`/en/...` 默认，`/ms/ /ko/ /ja/` 架构就绪、按三门槛解锁（见第六章附二）。

```
/en/（首页）
/en/tours/first-night-chongqing（英雄产品 ¥399）
/en/tours/first-night-family（细分：亲子版 P1，学 Anjia）
/en/tours/concierge（引流款 ¥199）
/en/tours/private（高端线，申请制）
/en/add-ons（加购：美食深扫/旅拍/续程包；含 non-spicy 细分页）
/en/guide/（攻略中心，首批 10 篇规划）
/en/hosts/（P2：host 人格化主页，学 Withlocals/TBL）
/en/reviews（全量评价含中评，可筛选）
/en/about · /en/faq · /en/legal · /en/booking
```

导航仅 5 项：Tours · Guide · Reviews · About · FAQ。预订 CTA 全站悬浮（移动端底部固定条）。

## 三、核心页面需求（要点版，详规继承 v0.1）

- **首页**：一句话定位 + 实拍视频背景（克制）+ 双 CTA + 信任条（Google 评分/服务人数/随时退）+ 评价轮播（含 1 条 4 星中评及我方回应——全公开策略视觉化）+ 产品三卡（价格直接上卡）+ "为什么是我们"六空位 + 攻略导流 + 零购物承诺横幅。
- **产品详情页模板**：逐小时时间表 → 集合点照片级指引 → 包含/不包含 → 体力/饮食要求 → 退改政策（随时退+30 分钟不满意全退醒目）→ 3 条真实评价 → 专属 FAQ 5 问 → 三币种切换 → CTA（¥100 订金）。
- **攻略中心**：step-by-step + 实拍图 + "外国人踩过的坑"侧栏；每篇底部软 CTA。
- **评价页**：全量展示 + 筛选器；中评必须可见且下方有公开回应；**禁止任何评价隐藏**（承诺即壁垒）。
- **预订流程四步**：选产品/日期 → 填信息（护照名+WhatsApp+航班号）→ 支付订金 → 确认单（照片级落地指引 + 助理 WhatsApp 直连）。目标 4 分钟完成，移动优先。

## 五、性能与体验预算

Lighthouse 移动 ≥90 四项；首屏 LCP ≤2.5s（4G）；图片 WebP/AVIF+懒加载；视频仅首屏一条；全站英文原生文案（专业+有性格的朋友口吻，禁客服腔）。

## 六、技术路线（v0.2 重写：基于 14 站逆向证据的终版论证）

### 6.1 证据：竞品技术栈全景（docs/research/25，2026-11-03 一手抓取）

| 派别 | 代表 | 技术栈 | 首页 HTML 体积 | 经营结果 |
|---|---|---|---|---|
| 现代 React/Next 派 | ToursByLocals | Next.js | **878 KB** | 全球向导平台头部 |
| | Withlocals | Next.js+CF | 539 KB | 欧洲头部，7 语种 |
| | GuruWalk | Next.js+WP+CF | 566 KB | 免费徒步头部（无中国供给） |
| | 240 | Next.js | 878 KB | 11 语种细分新秀 |
| 轻量传统派 | China Highlights | Bootstrap 服务端渲染 | **193 KB** | 20 年老牌，依然增长 |
| | Civitatis | **PHP** | 283 KB | 西语市场第一，全球化扩张 |
| | Anjia | 静态定制站 | **~30 KB** | 本地头部，月 20–30 单 |
| 异类 | Context Travel | **Ruby on Rails** | 878 KB | 高端叙事，客单 US$1,000+ |
| 自家候选 | — | **Astro（静态优先）** | 目标 ≤150 KB | — |

### 6.2 三个被认真考虑过的替代方案及弃选理由

1. **Next.js（240 同款）**：唯一能把 11 语种与复杂交互一次做全的现代方案。弃选原因：证据显示 Next 派首页 HTML 540–878KB，是轻量派的 3–4.5 倍——对以海外移动流量+Google 排名为命脉的我们，这是持续性税负；且 Lawson 实验证明其在 AI 生成/迭代成本上最贵。我们的四语种需求用 Astro i18n 同样可满足（240 证明了需求可行性，我们只需避免它的体积代价）。
2. **PHP/传统服务端（Civitatis/CH 路线）**：商业上最成功的两家中就有两家在用，证明"轻量=长寿"。弃选原因：它们的成功建立在十几年内容资产上，而我们要在 6 个月内靠 AI 产出同等密度的内容资产——现代内容管线（MDX、图像优化、结构化数据、Git 工作流）对 PHP 老站是逆向工程，对 Astro 是原生能力。学它们的"轻"，不学它们的"旧"。
3. **极简静态站（Anjia 路线，~30KB）**：本地转化效率已被 Anjia 验证（月 20–30 单）。弃选原因：Anjia 的轻是以牺牲攻略内容、SEO 深度、交互体验换来的——我们恰恰要打"审美即战略"和"内容密度第一"两场仗，30KB 的极简框架撑不起这两场仗。

### 6.3 定栈（不变，但证据升级）

| 层 | 选型 | 本轮新增证据支撑 |
|---|---|---|
| 框架 | **Astro（SSG）** | 14 站数据 = "轻量派经营胜"（Civitatis/CH）+ "现代派体重大"（Next 派 540–878KB）；Astro 是唯一同时占据轻量与现代内容管线的选项 |
| 样式 | Tailwind CSS | 不变 |
| 内容 | Markdown/MDX in Git | 学 CH 的内容资产路线，但用现代管线加速 10 倍 |
| 预订/支付 | Stripe 托管收银台 ¥100 订金 + 境内尾款 | Anjia"轻订金锁档+境内结算"闭环已验证（24 号文档） |
| 函数 | Cloudflare Pages Functions（仅 webhook/表单） | 不变 |
| 分析 | Umami + Cloudflare Analytics | 不变 |
| 媒体 | Cloudflare R2/Images + WebP/AVIF | 不变 |
| i18n | Astro i18n 路由（en/ms/ko/ja） | 240 证明 Next 能做 11 语种；我们用 1/3 体积做 4 语种 |
| 部署 | Cloudflare Pages 全球 CDN | 客户全在海外；CH/Civitatis 的轻量正是 CDN 友好的产物形态 |

**自检指标（冒烟验证，11.10 前）**：同一产品页 Astro vs Next.js 原型对比——AI 生成 token 消耗、构建产物大小、Lighthouse 移动分；通过标准：体积 ≤ Next 版 1/3 且 Lighthouse ≥90。若实测未达，触发回退评审（赛马机制保留此出口）。

## 六之附二、多语言蓝图

四语种架构就绪、英文先行：英语 / 马来-印尼语 / 韩语 / 日语（依据 24 号文档客源实证）。解锁三门槛：① 该语种咨询占比 ≥15%；② 顾问级翻译校对（法律文本必须人工）；③ 客服能接待。二期候选：西语、俄语、泰语。
