# 两项服务都试，用市场结果决定侧重

日期：2026-11-02 · 状态：**实验设计草案，尚未招募、销售或交付**

## 1. 发起人的校正与本轮问题

发起人原话：“现在不是我希望，应该是市场需求是如何？我觉得这两个都可以，最重要的是哪个能跑通？或者来尝试”。

本轮不问“我们更喜欢哪一种”，而问：**哪些真实游客，在什么情境下，会按可持续价格购买哪种服务？我们能否找到他们，并反复完成交付？**

现有资料不足以回答谁能跑通。Codex认为具体陪同可能更易让人理解购买内容，远程服务可能更灵活，但待命成本容易漏算；这只是两个待检验的判断。一个产品有人买、一个有助于获客、一个适合加购，也可能同时成立。

## 2. 两项分别标价，不强迫二选一

以下为服务范围候选，全部属于**假设**。真实售卖前根据经营伙伴、人员、收退款与成本条件调整并定稿。

| | A 预约现场陪同 | B 限定行中远程协助 |
|---|---|---|
| 购买任务 | 把第一晚玩好、吃好，之后更能自行出游 | 自己旅行，遇到具体的本地沟通或确认事项有人协助 |
| 初测人群 | 已有来渝日期的成年1—4人旅行组，以英语沟通 | 同样记录英语沟通与自主旅行需求；不默认所有A买家都需要B |
| 初测内容 | 一个主城片区约3小时：街区体验、点餐协助、返程/换乘指引 | 约定连续72小时的白天/晚间服务窗口；最多3次本地确认或沟通事项，累计主动处理上限60分钟 |
| 共同边界 | 餐费、车辆、门票等另计；由合适主体按实际内容经营履约 | 不含到场、全天导游、代付资金、无限代办；不是医疗或紧急救援保障 |
| 时间安排 | 可预约日期与时段 | 候选窗口北京时间09:00—21:00；首响与处理承诺须先经排班演练确认，未定稿不收费销售 |
| 定价方法 | 先拿现场人员、协调、保险及渠道成本，确定一个可持续总价 | 先算处理、售前售后、支付及待命成本，再决定价格与范围 |
| 可用于讨论的金额 | ¥899/组仅作成本情景和产品卡刺激物；不是已定售价 | ¥199/72小时仅作刺激物，不是已定售价；不能因接近竞品报价就假定可盈利 |

**比较方式**：两项各有完整价格、包含项、时段、取消与实际经营主体信息。允许A、B、A+B或都不买；首轮A+B按两项价格相加，先不靠组合折扣改变选择。不把B免费塞入A后，再宣称B需求得到证明。

两项不是完全相同产品，不以成交率高低直接判断输赢；价格与范围不同带来的选择原因也要记录。展示顺序交替，减少销售人员总先介绍自己偏好方案的影响。

## 3. 14天怎样安排

准备阶段先做短访谈、伙伴报价、产品卡与收退款/排班确认。**14天从两项都能诚实报价、可承接订单时开始**，不是从写好文档时开始。准备未完成可以继续做经历访谈和清楚标注的概念选择，不能记为真实付费验证。

| 时间 | 动作 | 产出 |
|---|---|---|
| 准备期 | 约6—10名有真实经历的游客做短访谈，补两个产品的成本与交付条件；定稿两张服务卡 | 假设、实际报价基础、可服务日期；正式销售前的缺口 |
| 第1—3天 | 通过一个可控入口接触有明确日期/近期在渝的适配旅行组；先了解原有解决方式，再展示两张卡 | 真实问题、是否理解内容、拒绝原因；非强制选择 |
| 第4—10天 | 争取累计约20个旅行组看过两项完整报价；记录A/B/两项/都不买、价格与付款。仅用得到许可的住宿转介或主动咨询等入口 | 产品选择与报价漏斗；来源、熟人/非熟人和优惠分开 |
| 第4—14天 | 按真实需求交付少量订单，初期总量约6—10组以内；现场一天先限一组；远程先限同时在途两组，且现场与客服不能双重占用同一个人的承诺时段 | 主动工时、待命时段、成本、需求超界、反馈与退款记录 |
| 第14天 | 只作第一次复盘：哪个值得继续、如何减项/改价、是否需要第二批 | 初步判断、证据缺口、下一次小实验 |

数字是控制试验规模的建议，不是市场预测或必达业绩。两周只有5组适配报价，结论应是样本不足；不能认定另外15组本来会拒绝，也不能断言市场不存在。

访谈激励、公开推广、实际收费和交付尚未执行。本文件本身不代表已经取得入口、伙伴或支付能力。

## 4. “跑通”的四个检查点

1. **有人付钱**：真实日期、非熟人、清楚完整价格与边界后实际付款。口头喜欢、免费参与、可退意向金另记。
2. **找到这些人有可重复路径**：记录每个入口、接触人时、合格报价与首单成本。熟人首单可以学交付，不能当作陌生客获客已经成立。
3. **交付后有可持续余量**：计算整个订单与本地通自身实际收益；扣除现场人员、渠道、收退款、售前售后和远程待命容量，不依赖创始人免费超时。
4. **下一批还能做到**：在另一批客人、另一个时段或另一名人员上复现。第一轮几单只能筛方向，不能宣布商业模式成立。

除单笔收益，还看每次合格报价带来的实际净贡献及总投入人时。¥199产品的成交率高于¥899产品，不代表它更有商业价值；反过来也不能只看高客单而忽略获客与履约。

## 5. 可能得到的六种结果

| 结果 | 下一步含义 |
|---|---|
| A独立购买与交付较好，B很少单买 | A可能做主产品；B是否加购继续验证，不强做独立业务 |
| B独立购买较好，扣待命成本后仍可持续 | B可能做主产品；现场作为另行报价的升级 |
| 两项都有人独立购买，且各自能持续 | 两项保留，明确各自客群和排班，不为选冠军而删掉需求 |
| 大部分人两项都不买 | 先看现有替代、价格、时机与信任，区分产品问题和入口问题；限定一次修改再测试 |
| 有人付钱，但人时或异常成本吃掉收益 | 需求可能存在，当前交易结构没跑通；改范围、价格或交付方式 |
| 没接触到足够适配客人 | 首先暴露获客困难；为这个入口设投入上限，不用继续写报告假装补齐样本 |

若只有A+B组合有人买，不直接声称两项都能独立成立：下一轮查看各项使用、价值归因，以及取消其中一项后是否仍愿付款。

## 6. 接下来让Claude反驳什么

- 两项服务的边界是否贴近游客任务，还是我们为了便于运营而定义的？
- 什么人、哪个购买时机可能被这个样本方案漏掉？
- 价格、展示顺序、渠道或组合购买，是否会让我们误判？
- 哪个结果能真正推翻“现场优先”，哪个能推翻“远程低成本”？

目标是提高实验能否区分问题的能力，不是比谁能更有说服力地选一个方向。
