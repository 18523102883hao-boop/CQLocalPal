## 一、终稿裁定

**开发执行基准 = Codex PRD v0.2**（`docs/plans/2026-11-03-官网PRD-v0.2-Codex.md`），Kimi v0.1/v0.2 中已被其吸收的业务内容（四语种蓝图、信任组件体系、双轨收款、细分页、hosts 页）不再另立文本。

**为什么以 Codex 版为基准（三条硬理由）：**

1. **它纠了真错**：Anjia 支付页实测为 **AsiaPay/PayDollar + 20% 订金 + 公司账户 + 境内尾款**（不是"WhatsApp 人工收款"）；Jay 技术指纹为 Airo+React（25 号的"WordPress 痕迹"作废）；878KB 是抓取脚本 90 万字符截断换算值，不能当精确体积证据；"月 20–30 单"归于 Jay 而非 Anjia。这些错误 Kimi 版（含本作者所写）照单全收。
2. **交易完整性远胜**：Payment Links 一句话方案 vs Codex 的订单状态机、库存防重售、回调验签、幂等、outbox、PDF/邮件补偿、真实退款定义——收款恰恰是"无代码创始人最怕出故障"的环节。
3. **合规更稳**：删除评价激励（Google 明令禁止）、删除 FAQ/HowTo 富摘要承诺（Google 已撤销支持）、自站不自标星级、不以"订金"冒充法定"定金"。

## 二、会议新约束下的 MVP 收敛（"Jay 模式先立起来"）

Jay 模式 = 少页面、快上线、WhatsApp 承接、¥100 订金闭环、评价驱动。**在此约束下对 Codex 排期做如下收敛**（其余条款不变）：

| 阶段 | 上线内容（P0 收敛） | 日期 |
|---|---|---|
| M1 首页+英雄页 | 真文案、授权实拍、明码价、信任条、WhatsApp+订金双 CTA | 11.14 |
| M2 全站交易闭环 | 三产品页 + family/non-spicy 细分 + hosts（≥1 真实具名 host）+ About/FAQ/Legal + 预订订金流 + 5 篇种子攻略；评价页以诚实空态上线 | 11.17 |
| M3 内容加厚 | 攻略补至 10 篇；评价随首单开始积累；sitemap 提交 | 11.24 |

**明确不进 v1（按会议"先进入领域"原则封存）**：AI 行程规划工具、PWA 安装/推送（静态站+离线 PDF 已覆盖其核心诉求）、多城市、B2B 门户、武隆票务代售、Free Night Walk、App/账户系统——全部进 P2  backlog，另行立项。

## 三、技术路线终判

- **框架：Astro SSG + TypeScript + 原生 scoped CSS + Content Collections + Cloudflare（Static Assets + Workers + D1 + R2 + Queues）**。判胜规则按 Codex 4.7：11.10 前完成三栈（Astro/Next 静态导出/Eleventy）同规格赛马，硬门槛（功能用例+移动四项 ≥90+LCP≤2.5s+首访 JS≤80KiB）不过线者一票否决；综合分差距 <10 保留 Astro。
- **支付：AsiaPay/PayDollar 托管收银台为首选**（贴合境内持牌主体，11.05 启动申请）；Stripe Checkout 仅在有真实获批主体时启用适配器；两者皆无 → 生产只开 WhatsApp/表单询单，11.17"可收真实订金"里程碑如实判未通过（不假上线）。
- **分析/邮件/PDF**：Plausible Cloud Business 单一分析 + Resend 邮件 + pdf-lib 固定模板 PDF（非实时 AI 生成）。
- **i18n**：`en/ms/ko/ja` 四路由架构就绪，`en` 唯一发布，三门槛（28 天询单占比 ≥15% + 顾问签署校对 + 值守通过 10 组模拟对话）缺一不发布。

## 四、关键修正点（开发时逐条执行，源自 Codex 评议，Kimi 方案相应作废）

1. 支付主选 AsiaPay；不为用 Stripe 虚构海外主体；不用个人收款码。
2. 订单必须服务端核价/库存事务/验签回调/幂等；杜绝"两个付款链接"方案。
3. 30 分钟满意保证从服务实际开始时间计；开始前随时取消全退含订金；零购物违约全退不受 30 分钟限制。
4. 评价零激励；全量公开含中差评；无真实评价用诚实空态，禁止假 4 星。
5. 不收护照号/敏感信息；航班号仅接机产品必填；过敏需求单独授权通道。
6. `approvedForSale` 机制：未经运营核准成本与范围的 SKU 只展示筹备状态、只接询单，禁止演示价收款。
7. 单个产品页 HTML 目标 ≤100KiB；首页首屏总传输 ≤500KiB；无自动播放视频、无轮播库、无地图 iframe。
