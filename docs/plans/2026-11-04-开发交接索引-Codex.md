## 2. 已确定的产品与技术决定

1. **主推¥200远程支持**，不是¥199。试运营默认：一单1–4人、连续72小时行中窗口、一次免费20分钟行前沟通；08:00–24:00北京时间值守，30分钟真人首响。窗口与人力属于试验假设，不能声称是Jay原合同。
2. **完整官网MVP**：首页、Concierge/首晚/私享三主产品、family/non-spicy细分、真实hosts、5篇攻略、预订订金/确认PDF/退款、评价/FAQ/About/法务。
3. **完整展示与真实可售分开**：远程服务条件齐备后开放；未备齐人员/供应商的其他产品只询单，不收占位订金。
4. **收款先用合格商户渠道＋人工核销**：默认CNY100订金、CNY100尾款；不以客户截图/返回URL作为支付真值。USD15仅实际通道与抵扣规则批准后开启。
5. **Astro静态官网＋TypeScript＋原生CSS＋Git内容管理**。Cloudflare托管和小型订单服务；D1/R2/队列/邮件用于订单闭环。PWA用Workbox injectManifest，同库、同内容源，不引入独立App。
6. **PWA v1必须包含**可选主屏入口、主动保存5篇公共资料、离线阅读、完整性/失效/更新/清除；不包含离线付款/聊天/私有订单缓存/推送。
7. **英语先上**，`/ms /ko /ja`结构就绪但不伪造翻译页面；满足客源、顾问校对、客服能力后才解锁。
8. **社媒现在准备与开通**；Instagram＋YouTube主要生产内容，其他平台分工；供应商转介绍放下一阶段。
9. **旧结论明确废止**：PWA一律暂缓；¥199/24h；无自动网关一律不能接首单；Jay远程月20–30单；二维码天然适用于所有海外银行卡；有PWA就能离线付款；未核验人员/评价/价格可以先作为真资料发布。

## 4. 开发所需现实输入与缺失时行为

| 输入 | 由谁提供 | 缺失时开发AI应做什么 |
|---|---|---|
| 正式域名、真实WhatsApp、备用邮箱/电话 | 发起人/账号所有者 | 明确测试配置；生产禁止假号码/无效链接；不替用户抢注或注册 |
| 实际经营与收款主体、商用通道许可、退款方法 | 经营/收款负责人 | `PAYMENT_MODE=inquiry`；完成manual/mock流程，不显示可用收款码 |
| 主/备英语服务人员、照片授权、排班 | 服务负责人 | host空态、产品inquiry；不生成人物履历或“认证”标识 |
| SKU价格、范围和政策批准记录 | 产品/经营负责人 | 按PRD假设实现预览；未批准只展示明确拟议价，不收款 |
| 核准商家码、测试交易结果 | 收款负责人 | 仅私有配置/系统；不存个人转账码或交易资料到Git |
| 自动网关技术包/签名密钥 | 网关与账号所有者 | provider接口与mock可交付；真实网关标未接入，不自造验签协议 |
| 5篇事实核验、英文校对、实拍授权 | 内容负责人 | 有模板和草稿但不冒充approved；资料包未批准则禁用保存按钮 |
| Cloudflare/邮件/分析访问权限 | 账号所有者 | 提供配置说明和本地mock，不新购付费方案；默认不自动扩大权限 |
| 线下服务机构/车辆/资质合同 | 资源负责人 | 页面仍可询单；不开放对应SKU付款，不代替供应商承诺 |

外部配置至少区分环境、网站URL、联系方式、服务主体、PAYMENT_MODE、商户通道、D1/R2/Queue绑定、邮件域名与凭据、Access应用受众、加密secret、分析站点。公开变量与服务器secret分离；样例只给无效占位值，真实值由账号所有者注入。
