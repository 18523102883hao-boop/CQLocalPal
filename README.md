## 项目一句话

外国人到重庆，缺的不是攻略，而是一个**有血有肉、随时在线的本地真人**：订酒店、订车、推荐地道火锅、处理纠纷、解决支付与证件难题。我们做这个「本地通」，人均消费低、服务确实好，靠口碑与外网内容获客。

## 背景速览

- **市场（早期估算，未核实，勿直接引用）**：曾估计重庆年接待外国游客约 260 万–300 万、上海 700–900 万，并判断“供给不足、质量不足”。后续官方口径与研究结论见 `docs/research/09` 第 3 章；不要把早期估算当作市场事实。
- **政策红利**：240 小时过境免签（10 天纯旅游过境，多国适用），入境流量持续放大。
- **游客痛点（早期观察，非随机样本）**（解放碑实地观察 + 外部朋友反馈）：
  1. 国际手机号收不到短信验证，无法完成各类注册/预约；
  2. 住宿登记流程对外国人不友好；
  3. 部分景区证件不认国外护照；
  4. 货币支付障碍；
  5. 更深层的刚需——**事务性协助**：订酒店订车、攻略咨询、夜间协助、纠纷处理（打 110 时英语沟通困难，往往不了了之）。
- **已排除的方向**：上海「城市一卡通」式重资产模式（需打通交通/法规/政府资源，筹备重、周期长，不适合起步）。

## 核心原则（早期共识，部分已被调研修正）

- **轻资产、小而美**：先吃中间一小块蛋糕，先进去验证需求，不做大平台；
- **AI 辅助 + 真人履约（早期称“反 AI”）**：用 AI 降低获客和需求整理成本；用本地人、本地资源和持牌履约解决 AI 难以稳定保证的实时确认、现场执行和责任承担；
- **不做国内生意**：只做老外市场，摸准需求后反向与商家谈资源；
- **闭环逻辑**：收费不贵 + 资源折扣（订酒店/订车有优势价差）→ 游客觉得「买不到吃亏」→ 口碑传播；
- **并行推进**：杰文线（重庆景区上架海外平台）继续跑，真人助理为主线。
